How to upload into GitHub:

  1. Click "Download 512×512 PNG" above to save truecalci-logo-512.png to your device.
  2. Go to your GitHub App / OAuth App page:
    GitHub Developer Settings → OAuth Apps.
  3. Select your OAuth App (or click New OAuth App).
  4. Under Application logo, drag and drop the downloaded truecalci-logo-512.png file.
  5. Click Upload logo (or Update application) at the bottom.
