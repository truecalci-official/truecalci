Frequently Asked Questions

How does TrueCalci eliminate LLM mathematical hallucinations?
Large language models are probabilistic token predictors that frequently produce arithmetic errors on complex multi-tier tax brackets, mortgage amortizations, and compound schedules. TrueCalci offloads the computation to deterministic IEEE 754 engines running at Cloudflare's global edge, returning verified results with 100% mathematical certainty.
How does the Streamable HTTP MCP endpoint work with AI agents?
TrueCalci provides an open JSON-RPC 2.0 endpoint at https://truecalci.com/api/v1/mcp. AI agents in Claude Desktop, Cursor, LangChain, and custom Python agents connect over standard HTTPS POST without requiring a local Node process or stdio adapter.
What is included in the 10,000 monthly request quota for Pro Agency?
Pro Agency includes 10,000 edge calculation requests per calendar month (or 120,000 requests upfront with annual billing), 1,000 req/min burst speed, multi-seat API keys, priority edge routing, and automated compliance tax invoices.
How does team access and multi-seat API key management work?
Pro and Enterprise tiers allow you to generate distinct personal and shared team API keys. You can provision separate keys for staging, production, autonomous agent pipelines, and individual team members without sharing credentials.
How do overages work on the Enterprise Pay-As-You-Go plan?
On Enterprise Pay-As-You-Go, you are never hard-capped or rate-blocked. You receive 10,000 included base requests, and any excess requests are billed at a predictable flat rate of $1.00 per 1,000 requests (or ₹80 per 1,000 in India) with transparent real-time usage meters.
Do you store any computational inputs?
No. TrueCalci guarantees zero persistent storage for computational payloads. All statutory algorithms run inside transient Cloudflare V8 memory isolates and are wiped immediately upon response delivery.
Which payment methods do you accept?
We accept global Visa, Mastercard, American Express, Apple Pay, and Google Pay. For Indian developers, we natively support UPI AutoPay and RuPay via Dodo Payments (Merchant of Record). Invoices include automated GST and VAT tax compliance.
Can I cancel or upgrade at any time?
Yes. Upgrades take effect immediately with prorated billing. You can cancel with a single click from your Subscriptions dashboard, and access continues until the end of your billing cycle.
